Cómo funciona

Así es como funciona

Tú fijas el descuento, la meta y la fecha. Se inicia cuando el primero se une y tiene 24 horas para meter a otra persona.

admin.shopify.com/apps/tuko

admin.shopify.com/apps/tuko/estadisticas

01/ 04

  1. Elige un producto o todos los que quieras de tu catálogo. Decides el descuento y solo se aplica cuando hay 2 personas.

  2. Paga con el descuento ya aplicado y tiene 24 horas para traer a una persona más. La comparte por WhatsApp o la trae tu propio tráfico.

  3. Cuando se une la segunda persona, el grupo se completa, se ejecuta el pedido y Tuko abre un grupo nuevo. El botón nunca se apaga.

  4. Cuando el grupo se completa, se ejecutan los pedidos y, a los 2 minutos, Tuko publica un grupo nuevo vacío, listo para el siguiente cliente. Tú no haces nada: se repite hasta que tú digas basta.
